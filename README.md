
# Alex Remote

Remote Android control from iPhone.

## Project goal

Alex Remote is an iPhone application designed to remotely access and control a personally owned Android device.

## Target device

- Samsung Galaxy A12

## Main features

- Remote screen viewing
- Touch and swipe control
- Launching applications
- Remote connection over the internet
- Secure device pairing

## Platform

- Client: iOS
- Target: Android
- Development: Flutter / native iOS components

## Important

The project will not require a permanently installed companion application on Android.

The connection will use Android's built-in debugging capabilities where supported.

ADB must never be exposed directly to the public internet.
